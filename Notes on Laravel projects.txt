Setting up a Laravel project

1. composer create-project laravel/laravel 'name-project'
2. db setup + env. file + php artisan migrate

3. make models (Eloquent ORM): php artisan make:model model-name
4. define relations in the models

5. migrations: php artisan make:migration 'create_names_table' (important: which migration should occur first?)
6. seeders and factories: php artisan make:'what' 'NameWhat'
7. use the models and factories in the seeders: use App\Models\'Name';, use Illuminate\Database\Eloquent\Factories\HasFactory; (in model), use HasFactory; (in model)
8. fill seeders: Category::factory()->count(x)->create();
9. change the DatabaseSeeder to call both seeders, then use php artisan migrate:fresh --seed

10. add routing in routes\web.php for http requests

11. add blades (resources\views) including Partials (e.g., nav) and Layouts (app.blade.php in layouts folder)
12. add layout and nav partial with Blade Syntax

13. create controllers: php artisan make:controller NameController
14. edit routes to render the blades by using the controllers

15. use Eloquent Models to retrieve data to be displayed in the view: e.g., Post::findOrFail(); Post::orderBy('date', 'asc')->get();

16. display the data using Blade methods(?) in the corresponding view/blade

Notes for Laravel project continued



Adding data:

1\. create a form with a post method: action="{{ route('data.store') }}" method="POST" /n @csrf

2\. add the corresponding route that points to the controller

3\. in the controller, create a new instance of the data (using the model) and populate it with data using $request. finally, use the $data->save() method. Optionally: add a return redirect()->route('name.route')



Deleting data (with *route model binding*):

1\. add delete button with a post method: action="{{ route('data.destroy', *$data*) }}" method="POST" /n @csrf /n @method('DELETE")

2\. add the corresponding route that points to the controller: Route::delete('/posts/*{post}*', ...)->name(...);

3\. in the controller, call the delete method on $data
